## AOT DAM 标注落地（第一批：LightORM 调用侧泛型类）

### 背景与关键事实（纠正 09-21 判断）

LightORM 源码在 `F:\GitRepositories\LightORM`（另有 `LightORM2`、`F:\LightORM` 副本，活跃的是 `F:\GitRepositories\LightORM`）。

**LightORM 侧 DAM 标注现状**（`src/LightORM/Interfaces/IExpressionContext.cs`）：
- `IContext.Select<T>()` / `IExpressionContext.Union<T>()` / `UnionAll<T>` / `FromQuery<T>` / `FromTemp<T>`
  → **已标** `[DynamicallyAccessedMembers(PublicConstructors | PublicProperties)]`（`NET8_0_OR_GREATER` 下）。
- `IContext.Insert<T>()` / `Update<T>()` / `Delete<T>()` → **未标**（裸 T）。
- `IExpSelect<T1>.InnerJoin<TJoin>()` / `LeftJoin<TJoin>` 等 join 方法的 `TJoin` → **未标**（裸 TJoin）。

⇒ 之前以为"LightORM 泛型 API 没标 DAM"是错的：`Select` 一路已标，是**我们调用侧泛型类没把 DAM 约束传递下去**；`Insert/Update/Delete/InnerJoin` 才是真缺口（本仓库改不了，需在 LightORM 仓库补）。

### 本次改动（本仓库 ClientCore，3 个文件）

给调用侧泛型类补 `[DynamicallyAccessedMembers(PublicConstructors | PublicProperties)]`（对齐 LightORM 已标的 `Select<T>` 要求）：

1. `DefaultServicesImpl/DefaultUserService.cs` —— `TUser`、`TUserRole` 两个泛型参数补 DAM。
2. `DefaultServicesImpl/DefaultPermissionService.cs` —— `TPower`/`TRole`/`TRolePower`/`TUserRole` 四个补 DAM。
3. `DefaultServicesImpl/DefaultRunLogService.cs` —— `TRunLog` 补 DAM。

（`CrudBase<T>` 与 `ICrud<T>` 在此之前已标 DAM，本次未动；`CrudBase` 还重构出 `DefaultContext => context.SwitchDatabase("MainDb")` 属性，是既有改动。）
