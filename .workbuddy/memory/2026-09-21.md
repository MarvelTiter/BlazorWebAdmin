  直接返回表达式树里的 `PropertyInfo`（`selector.Body is MemberExpression body && body.Member is PropertyInfo prop`），
  没有 `type.GetProperty(prop.Name, prop.PropertyType)` 重取。旧记录里的行号是过时的。
  ⇒ 现在仅剩的 IL2090 是 `Utils/ConditionUnitHelper.cs:88`。

  第 81 行 `Expression.Property(pExp, info.Name)` 已经用字符串拿到 PropertyInfo（顺带报 IL2026），

## WASM AOT vs Native AOT 的口径（答用户疑问，记档）

- **"WASM 支持 AOT"** = .NET 7+ 的 BlazorWebAssembly 用 **Mono AOT**（IL 预编译成 wasm + 解释器兜底）。
- **"官方说不支持 AOT"** = 指 **Native AOT**（`PublishAot=true`，无 JIT/解释器、激进裁剪）不适用于
  Blazor 组件模型（RenderTreeBuilder 反射渲染、@bind 字符串匹配 [Parameter]、DI/表达式树动态代码）。
- 二者不矛盾。本项目"为 AOT 做准备"= 让代码在 **Mono AOT 裁剪器 + 静态分析**下干净，
  尽量不依赖解释器兜底。这也解释了 R1/R2/R3 分级依据：
  `Expression<TDelegate>.Compile()` 在 Mono AOT 下安全（不报 IL3050），
  `MakeGenericMethod(值类型)` 连 Mono AOT 都无法静态生成（报 IL3050+IL2060）。
